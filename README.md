# 🌡️ Oil Well Temperature Predictor

A machine learning project that uses linear regression to predict oil well temperatures based on historical data from the Volve Oil Field (2007–2010).

---

## 📘 Overview

This project involves:

- Using **Volve Oil Field dataset (2007–2010)** for analysis.
- Applying **Linear Regression** to predict oil well temperatures.
- Improving prediction accuracy through **data preprocessing** and **feature selection**.

---

## 🧰 Tools & Technologies

- **Python**
- **Pandas, NumPy** – Data handling and preprocessing
- **Scikit-learn** – Model training and evaluation
- **Matplotlib, Seaborn** – Data visualization
- **Jupyter Notebook** – Development environment

---

## 📁 Dataset

- Source: **Volve Field Dataset**
- Time period: **2007–2010**
- Contains historical measurements from oil wells, including temperature, pressure, and production-related features.
